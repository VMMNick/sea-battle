# Морський бій онлайн

Проста онлайн-гра "Морський бій" для двох гравців у реальному часі (WebSocket, без бази даних).

## Як грати

1. Один гравець відкриває сайт і тисне **«Створити нову гру»** — отримує код кімнати (4 символи).
2. Другий гравець відкриває той самий сайт, вводить код і тисне **«Приєднатися»**.
3. Обидва розставляють кораблі (клік — поставити, `R` або кнопка — обертати, є кнопка «Випадково»).
4. Бій: по черзі стріляєте по клітинках суперника. Влучання дає ще один постріл (класичне правило).
5. Перемагає той, хто першим потопить весь флот суперника.

Набір кораблів класичний: 1×4-палубний, 2×3-палубні, 3×2-палубні, 4×1-палубні. Кораблі не можуть торкатися один одного навіть по діагоналі — сервер це перевіряє.

## Запуск локально

```
npm install
node server.js
```

Відкрити `http://localhost:8080` у двох вкладках (або надіслати посилання другу, якщо порт відкритий назовні).

Порт можна змінити змінною середовища `PORT`.

## Деплой в інтернет (щоб грати з будь-ким по посиланню)

Гра — це звичайний Node.js застосунок з постійним WebSocket-з'єднанням, тож підходить будь-який хостинг, що тримає процес живим (не «безсерверний»/serverless). Найпростіші безкоштовні варіанти:

### Render.com (рекомендовано, є готовий `render.yaml`)
1. Заливаєте цю папку в репозиторій на GitHub.
2. На render.com: New → Blueprint → вибираєте репозиторій. Render сам прочитає `render.yaml` і розгорне сервіс.
3. Через пару хвилин отримаєте публічний URL типу `https://sea-battle-xxxx.onrender.com`.

### Railway.app
1. Заливаєте папку в GitHub-репозиторій (або встановлюєте Railway CLI і робите `railway up` прямо з цієї папки).
2. New Project → Deploy from GitHub repo.
3. Railway сам визначить, що це Node.js застосунок (`npm start`), і видасть публічний домен.

### Fly.io / інші
Підійде будь-який хостинг з підтримкою постійних Node.js процесів і WebSocket (Fly.io, Cyclic, Glitch тощо) — застосунок не використовує жодних специфічних для платформи функцій.

## Структура проєкту

```
server.js          — WebSocket-сервер, вся ігрова логіка (кімнати, розстановка, хід, перемога)
public/index.html   — розмітка сторінки
public/style.css    — стилі
public/client.js    — логіка інтерфейсу гравця, з'єднання по WebSocket
test/simulate.js    — автотест: дві "гри" через WebSocket грають повну партію до перемоги
test/e2e.js         — автотест інтерфейсу (Playwright): дві вкладки браузера грають через UI
```

## Тести

```
node server.js &                 # підняти сервер
URL=ws://localhost:8080 node test/simulate.js   # серверна логіка
URL=http://localhost:8080 node test/e2e.js      # UI (потрібен playwright)
```
